# Fittings Planner

Prototype for model fittings planning. From one calendar it produces:

- the **WhatsApp planning message** (`name > time > purpose > location > team`)
- the **budget tracker**: estimated vs real cost per fitting, budget left, copy to Excel
- **invoice summaries** grouped by agency

Opens on **invented sample fittings**. "Load Outlook calendar" accepts an Outlook .ics export, read in the browser and never uploaded. Single static file (`index.html`), no server.
